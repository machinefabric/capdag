# capdag CLI 1.571.5598

First release of the capdag CLI as a distributed product — a single
self-contained package (the `capdag` binary plus its bundled providers:
data, fetch, and model cartridges).

## Highlights

- **Run a cap directly.** `capdag <cap-alias-or-urn> [inputs…]` resolves the
  cap, finds the providing cartridge in the signed registry, downloads and
  verifies it if missing, and runs it inside a full bifaci host — with the
  bundled providers registered, so peer calls (e.g. model downloads) work.
  The cap's own declared interface (piped stdin, native flags, positional
  args) is respected exactly as when the cartridge is invoked directly.
- **Run a machine file.** `capdag run <file.machine> [inputs…]`.
- **Pipe discipline.** A single scalar result streams raw to stdout;
  sequences and fan-outs write named files and list their paths. Logs and
  progress go to stderr.
- **Signed, verified downloads.** Registry cartridge binaries are signed; the CLI verifies the full chain before anything runs.
- **`resolve` / `install`.** Inspect which cartridge provides a cap, or warm
  the local cache in CI without executing.
